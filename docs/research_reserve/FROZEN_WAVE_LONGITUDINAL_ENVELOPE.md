# Frozen Wave 纵向包络设计：独立研究储备

**状态：** PARK / 独立支线储备  
**记录日期：** 2026-08-06  
**与当前主线的关系：** 不属于“湍流—独立机械抖动联合最优”第一阶段的默认候选；保留为未来短论文、会议论文或低成本理论—数值研究入口。

## 一、为什么保留

Frozen Wave 的主要辨识度不是横向抗抖动，而是利用有限组等频 Bessel 分量合成预定的纵向强度包络，使近轴能量在一段传播距离内维持、起伏受控或按目标函数重新分配。

这一机制可能适合以下场景：

- 移动 FSO 链路的传播距离持续变化；
- 发射端不具备实时变焦或发散角连续调节能力；
- 距离估计、控制延迟或轴向位置存在不确定性；
- 同一静态发射光场需要覆盖一段距离区间；
- 需要研究湍流是否破坏预设纵向包络及其有限孔径可靠性。

它与当前主项目的区别是：

- 当前主项目关注横向机械角抖动如何改写抗湍流光场的排序和联合最优；
- Frozen Wave 支线更自然地关注纵向包络、距离变化和静态光场对动态调焦的替代边界；
- 纵向包络可设计不自动意味着抗整体横向偏移，因此不应强行并入当前主线。

## 二、候选科学问题

可压缩为：

> 在有限发射口径、有限总功率和有限接收孔径下，有限能量 Frozen Wave 的纵向包络设计能否提高一段传播距离区间内的最小接收功率、低分位接收功率或链路可用率；这种收益需要付出多少峰值功率、外围能量、发射口径和光场生成复杂度？

这里不要求 Frozen Wave 在所有条件下普适优于 Gaussian。允许得到以下类型的特定场景结论：

- 单一名义距离处的峰值功率较低，但距离区间内的最低接收功率更高；
- 以更大的外围能量或发射口径为代价，降低对距离反馈和动态调焦的要求；
- 在某一距离不确定范围内，固定 Frozen Wave 优于固定参数 Gaussian；
- 与逐距离动态优化的 Gaussian 相比仍有差距，但系统复杂度明显降低。

## 三、最小数学结构

零阶有限能量 Frozen Wave 可用以下形式作为起点：

\[
E_{\mathrm{FW}}(r,0)
=
C_0\,
\Pi\!\left(\frac{2r}{D_T}\right)
\exp\!\left(-\frac{r^2}{w_a^2}\right)
\sum_{n=-N}^{N} A_n J_0(k_{\rho n}r),
\]

\[
k_{zn}=Q+\frac{2\pi n}{L_d},
\qquad
k_{\rho n}=\sqrt{k^2-k_{zn}^2},
\]

\[
A_n=
\frac{1}{L_d}
\int_0^{L_d}
F(z)
\exp\!\left(-i\frac{2\pi n}{L_d}z\right)\,dz.
\]

其中：

- \(F(z)\)：目标纵向包络，可先取具有平滑边缘的平顶函数；
- \(N\)：Bessel 分量阶数范围；
- \(Q\)：纵向载波参数，影响横向主区尺度；
- \([z_1,z_2]\)：目标能量维持区间；
- \(w_a\)：有限能量包络和截断尺度；
- \(D_T\)：实际发射清孔径。

首轮不采用任意像素级优化。优先保持少量参数和可解释的纵向包络设计。

## 四、合理比较对象

至少包括：

1. 针对单一中心距离优化的固定 Gaussian；
2. 针对整个距离区间做 minimax 或低分位优化的固定 Gaussian；
3. 可选：两档或多档可切换 Gaussian；
4. Frozen Wave 固定发射方案；
5. 必要时加入 Bessel–Gaussian 以分离“普通近无衍射结构”和“纵向包络可编程”的作用。

比较不要求所有设计自由度完全归一，但必须建立资源账本：

- 总发射功率；
- 实际发射口径；
- 接收口径；
- 主区与外围能量比例；
- 光场生成效率与无用级次；
- 峰值功率和区间最低功率；
- 所需动态调节能力。

## 五、首轮最小证伪

仅在独立分支中开展，不与主线参数扫描混合。

### 第一步：无湍流、有限口径

- 复现目标纵向包络；
- 检查能量守恒、窗口截断和 FFT 回卷；
- 计算不同距离下的有限孔径接收功率；
- 建立主区、外围和截断损失的能量账本；
- 与固定 Gaussian 和区间优化 Gaussian 比较。

### 第二步：距离不确定统计

令接收距离 \(z\) 在给定区间内变化，计算：

- \(\min_z P_R(z)\)；
- 距离分布下的 \(Q_{5\%}(P_R)\)；
- 给定接收门限下的可用距离比例；
- 纵向区间长度与峰值/平均功率的 Pareto 关系。

### 第三步：仅在前两步出现非平凡折中后加入湍流

- 使用多相位屏检查预设纵向包络是否仍有统计意义；
- 优先研究有限孔径低尾功率，不以轴上峰值或单幅场形作为主结论；
- 横向机械抖动只作为压力测试，不作为该支线的核心创新叙事。

## 六、继续与停止条件

### 可继续

至少出现一项：

- 纵向包络长度与区间最低功率之间存在明确、非单调且可解释的最优折中；
- 固定 Frozen Wave 在合理距离变化区间内显著优于固定或区间优化 Gaussian；
- 能给出发射口径、主区尺度、纵向维持区间和有限孔径效率之间的标度关系或设计边界；
- 静态 Frozen Wave 能以可接受资源代价替代部分动态变焦或多档发散角控制。

### 应停止或仅保留负结果

- 优势只体现在归一化轴上峰值或场形相似度；
- 有限孔径接收功率始终被优化 Gaussian 明显压制，且不存在合理系统交换；
- 所谓纵向鲁棒性完全来自不可接受的大发射口径或外围能量；
- 包络区间加宽只导致性能单调下降，没有设计规律；
- 为获得结果必须不断增加任意 Bessel 系数或高维优化自由度；
- 与现有 Frozen Wave 湍流、障碍物或通信研究的实质差异无法成立。

## 七、论文定位

当前只应将其视为：

- 低成本理论—数值小论文候选；
- 会议论文或短篇传播研究储备；
- 未来在主项目基础传播代码成熟后可复用的独立验证问题。

不应预先表述为：

- Frozen Wave 已被证明优于 Gaussian；
- Frozen Wave 天然同时抗湍流和机械抖动；
- Frozen Wave 是无人机 FSO 的普适最优发射光场。

前序外部调研曾将其判断为值得两至四周最小证伪的候选，但该判断只代表研究入口存在，不构成性能、新颖性或期刊层级的确认。启动前仍需重新检查最新文献。
